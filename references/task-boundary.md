# 译前任务边界确认清单

动笔前确认以下事项，否则语言能力容易用错方向。

## 必答问题
- [ ] **文本类型与用途**：合同/法规/医学/技术手册/学术/营销？翻译尺度不同
  - 法律、专利、标准 → 准确+可追溯优先
  - 营销/品牌 → 可在不改变核心信息前提下本地化重构
- [ ] **目标读者**：专家 / 管理者 / 公众？
- [ ] **语言变体**：简体/繁体中文、英式/美式英语
- [ ] **客户要求与交付规范**：术语偏好、格式模板、保密要求、是否允许译注、是否保留修订记录
- [ ] **原文整体逻辑**：通读全文识别主题/论点/指代/条件限制/文体语域（禁止未理解上下文前逐句硬译）

## 建立术语表（glossary.json）
至少记录每项：
- 原文术语
- 标准译法
- 适用语境
- 禁用/不推荐译法
- 来源链接或出处
- 最终确认人及版本

## 建立风格指南（长篇/多人项目）
统一：标题层级 / 大小写 / 标点 / 数字 / 单位 / 日期 / 缩写首次出现方式 / 人称语气

## 术语统一原则
- 同一概念原则上只使用一个主译法
- 确需变化时，必须能说明语义/语法/场景上的理由
- **正文改了术语，表必须同步**（活文档）

## 本项目实例（可复用约定）
- 日期：年月日→阿拉伯数字；世纪/年代→中文数字
- 疾病 vs 病原体区分：COVID-19/新冠肺炎（疾病）、SARS-CoV-2/新冠病毒（病原体）
- 人名机构：首次出现"中文（英文原名）"，后续只用中文
