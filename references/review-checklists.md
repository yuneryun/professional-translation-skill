# 译后四轮审校清单

> 高风险文本（法律/医学/金融/工程安全/监管申报/公开发表）→ 增加领域第二审校人或隔夜再审。

## 第1轮：双语对照校审
- [ ] 漏译 / 多译
- [ ] 误译（词义错误）
- [ ] 逻辑偏移（条件/因果/转折/让步被改写）
- [ ] 术语不一致
- [ ] 语气强度变化（must/shall/should/may、可能/确定、建议/要求）
- [ ] **无依据增译**（原文没有的信息未加）

## 第2轮：术语与事实专项核查
- [ ] 数字、小数点、百分比、货币、单位及换算
- [ ] 日期、期限、版本号
- [ ] 人名、地名、机构名、品牌名、产品型号
- [ ] 法律法规/标准名称、条款号、案件号、文献出处
- [ ] 否定、双重否定、比较级、范围词、例外条款
- [ ] 缩写全称及首次出现形式
- [ ] 引文、脚注、参考文献、已有定译

## 第3轮：脱离原文单语通读
- [ ] 自然、清晰、无歧义
- [ ] 符合目标语言专业写作习惯（不像翻译腔）
- [ ] 人物观点归属保留（"按某人的说法…"）
- [ ] 直接引语口语张力 vs 叙述书面语区分

## 第4轮：格式与交付检查
- [ ] 版式、标题层级、编号
- [ ] 表格、图注、加粗、斜体、脚注位置
- [ ] 全角/半角、空格、标点规则
- [ ] 批注、版本号、客户模板要求

## 专项技巧
- **回译检查**：关键条款/否定结构/条件句/数值逻辑 → 译回原文比对是否偏移（不能替代双语审校）
- **OCR坑排查**：复核时回带文字层PDF比对（OCR会丢词漏句）
